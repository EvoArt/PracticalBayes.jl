Getting started

Here we fit a straight line to simulated data: we write a model, sample its posterior with NUTS, look at the result, and check the fit with posterior predictive draws.

Simulate some data

using PracticalBayes, Distributions, StableRNGs, Statistics

rng = StableRNG(1)
x = collect(range(0, 1; length=50))
y = 1.0 .+ 2.0 .* x .+ 0.3 .* randn(rng, 50)

The true intercept is 1, the slope 2 and the noise standard deviation 0.3.

Write the model

A model is a function marked with @model. Each ~ line gives a variable a distribution. α, β and σ are not arguments, so they are parameters. y is an argument holding data, so .~ observes each element of it.

@model function linreg(x, y)
    α ~ Normal(0, 10)
    β ~ Normal(0, 10)
    σ ~ Exponential(1)
    y .~ Normal.(α .+ β .* x, σ)
end

model = linreg(x, y)

Sample

We draw 1000 samples with NUTS. Before them, sample runs warm-up iterations that tune the sampler and are then dropped.

chn = sample(StableRNG(2), model, NUTS(), 1000; progress=false)
[ Info: Found initial step size 0.0125

Look at the result

The chain is indexed by parameter name. Each entry is a matrix with one row per draw and one column per chain.

mean(chn[:α]), mean(chn[:β]), mean(chn[:σ])
(0.92640164385104, 2.1449763129695456, 0.28243277693857133)

The posterior means are close to the values we simulated from.

Check the fit

To draw new data from the fitted model we build it again with the data replaced by missing values. fill(missing, 50) gives the shape of the output. predict then draws y once for each posterior draw, and returns them as a chain.

preds = predict(StableRNG(3), linreg(x, fill(missing, 50)), chn)
yrep = reduce(hcat, preds[:y])
size(yrep)
(50, 1000)

Each column of yrep is one simulated dataset. If the model fits, about 90% of the observations should fall inside their 90% predictive intervals:

lo = [quantile(r, 0.05) for r in eachrow(yrep)]
hi = [quantile(r, 0.95) for r in eachrow(yrep)]
mean(lo .<= y .<= hi)
0.92
